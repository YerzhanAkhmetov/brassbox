# Миграции схемы базы

- Файл: `NNN_имя.sql` (`001_init.sql`), номера строго 1, 2, 3… без пропусков.
- Номер базы — `PRAGMA user_version`; программа применяет недостающие при открытии.
- Каждая миграция — одна транзакция вместе с `user_version`: упала — откат целиком.
- Перед миграцией делается автокопия базы.
- Только совместимые изменения: старая программа видит «база новее» и не трогает её.
- Уже выпущенный файл не менять — только новый номер.
- Первая миграция (схема записей) — этап 3.
